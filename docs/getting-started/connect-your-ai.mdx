Connect your Trader account on Windows to check balances, positions and orders from your AI client. Local MCP starts in read-only mode.

[Choose your AI client](#configure-mcp-client)

## 1. Get your account settings

In Trading Terminal, open **API Key Management** and create a key with **Read** permission. Keep the key and connection settings for the same account. Enter them only in the local file named by setup.

## 2. Install and connect

**Install uv.** Run this in PowerShell.

```powershell
winget install --id=astral-sh.uv -e
```

Open a new PowerShell window and run `uvx --version`. [Other ways to install uv](https://docs.astral.sh/uv/getting-started/installation/#installation-methods).

**Verify the wheel.** Ask the release owner for the candidate `.whl` file, its SHA-256 and the dependency index URL. Keep the wheel in a permanent folder. Open that folder in PowerShell and run:

```powershell
Get-FileHash .\mft_trader_api_mcp-0.1.0-py3-none-any.whl -Algorithm SHA256
```

Continue only if the hash matches the supplied SHA-256.

**Run setup.** In the same folder, replace the index placeholder with the supplied URL and run:

```powershell
$env:MFT_TRADER_API_PACKAGE_INDEX = "<dependency index URL>"
uvx --no-config --no-env-file --managed-python --python 3.12 `
  --index $env:MFT_TRADER_API_PACKAGE_INDEX `
  --default-index https://pypi.org/simple `
  --from .\mft_trader_api_mcp-0.1.0-py3-none-any.whl trader-api-mcp-setup
```

Open the account file at the path printed by setup, fill it with the settings from step 1 and save it. Press Enter in PowerShell, then choose your AI client. Setup checks account access and prints the configuration for your client.

<details>
<summary>Account file fields</summary>

| Field | Source in API Key Management |
| --- | --- |
| `TRADER_API_KEY` | API key with Read permission |
| `TRADER_API_USERNAME` | `username` |
| `TRADER_API_TRADE_KEY` | `trade_key` |
| `TRADER_API_WEB_PROXY_URL` | WebProxy REST (`webproxy_endpoint`) |
| `TRADER_API_FXSERVER_REST_URL` | FxServer REST |
| `TRADER_API_FXSERVER_WS_URL` | FxServer WebSocket (`endpoint`) |
| `TRADER_API_PRICE_AGENT_WS_URL` | Price Agent WebSocket (`price_agent_endpoint`) |
| `TRADER_API_CHART_SERVER_URL` | ChartServer REST |

Copy the URLs as issued, including their base paths. The Python snippet may omit the REST URLs. Use the connection settings shown in the terminal, or ask account support for a missing value.

</details>

## 3. Check the connection

<CodeBlock className="mcpPrompt" language="text">{"Show my account balance, open positions and working orders. Do not place a trade."}</CodeBlock>

Ask in a new chat. The connection is working when the client calls an mFT Trader API MCP tool and returns your account data.

<details id="mcp-setup-troubleshooting">
<summary>Troubleshoot setup</summary>

- If setup fails, check `uvx --version`, the wheel hash and dependency index, and the account file.
- If the client cannot start MCP, check the generated paths and restart the client. Regenerate the entry if you moved the wheel or account file.
- For candidate support, use the channel supplied with the wheel. Keep credentials and raw logs out of chat.

</details>
