Use the API reference when you know which service or endpoint you need. The interactive references are generated from the public OpenAPI specifications.

## Choose an API

- [FxServer Trader API](./fx-server/openapi-trader.mdx) for deals, orders, positions, account state, and account updates.
- [WebProxy API](./web-proxy/openapi.mdx) for sessions, API keys, access tokens, account data, and contract settings.
- [Realtime Chart Server API](./realtime-chart-server/openapi.mdx) for chart bars, open prices, and market statistics.

For task-based workflows, start with the [Guides](./guides.md) or the [Trader API Client Starter Kit](https://github.com/mF-Technologies/trader-api-client-starter-kit).
