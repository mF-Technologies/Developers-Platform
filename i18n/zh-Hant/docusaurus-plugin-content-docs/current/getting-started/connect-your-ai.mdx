在 Windows 將 Trader 帳戶連接至 AI 用戶端，即可查看餘額、持倉及掛單。本機 MCP 預設為唯讀。

[選擇 AI 用戶端](#configure-mcp-client)

## 1. 取得帳戶設定

在交易終端開啟 **API Key Management**，建立具備 **Read** 權限的金鑰。請使用同一帳戶的金鑰及連接設定，並只填入設定程式指定的本機檔案。

## 2. 安裝並連接

**安裝 uv。** 在 PowerShell 執行以下指令。

```powershell
winget install --id=astral-sh.uv -e
```

開啟新的 PowerShell 視窗，執行 `uvx --version` 確認安裝成功。[其他 uv 安裝方式](https://docs.astral.sh/uv/getting-started/installation/#installation-methods)

**核對 wheel。** 向發佈負責人索取候選版 `.whl` 檔案、SHA-256 及依賴套件索引網址。將 wheel 保存在固定資料夾，在 PowerShell 前往該資料夾並執行以下指令。

```powershell
Get-FileHash .\mft_trader_api_mcp-0.1.0-py3-none-any.whl -Algorithm SHA256
```

確認雜湊值與獲發的 SHA-256 相符後再繼續。

**執行設定。** 在同一資料夾，將指令內的索引預留值換成獲發的網址，然後執行：

```powershell
$env:MFT_TRADER_API_PACKAGE_INDEX = "<dependency index URL>"
uvx --no-config --no-env-file --managed-python --python 3.12 `
  --index $env:MFT_TRADER_API_PACKAGE_INDEX `
  --default-index https://pypi.org/simple `
  --from .\mft_trader_api_mcp-0.1.0-py3-none-any.whl trader-api-mcp-setup
```

依照設定程式顯示的路徑開啟帳戶檔案，填入步驟 1 的資料並儲存。回到 PowerShell 按 Enter，選擇 AI 用戶端。程式會檢查帳戶存取並輸出該用戶端的設定。

<details>
<summary>帳戶檔案欄位</summary>

| 欄位 | API Key Management 來源 |
| --- | --- |
| `TRADER_API_KEY` | 具備 Read 權限的 API key |
| `TRADER_API_USERNAME` | `username` |
| `TRADER_API_TRADE_KEY` | `trade_key` |
| `TRADER_API_WEB_PROXY_URL` | WebProxy REST (`webproxy_endpoint`) |
| `TRADER_API_FXSERVER_REST_URL` | FxServer REST |
| `TRADER_API_FXSERVER_WS_URL` | FxServer WebSocket (`endpoint`) |
| `TRADER_API_PRICE_AGENT_WS_URL` | Price Agent WebSocket (`price_agent_endpoint`) |
| `TRADER_API_CHART_SERVER_URL` | ChartServer REST |

請複製獲發的完整網址，包括原有路徑。Python 範例可能沒有列出 REST 網址，請查看終端的連接設定。如有必填值缺漏，請聯絡帳戶支援。

</details>

## 3. 確認連接

<CodeBlock className="mcpPrompt" language="text">{"顯示我的帳戶餘額、持倉及掛單，不要落單。"}</CodeBlock>

在新對話提出以上問題。用戶端呼叫 mFT Trader API MCP 工具並返回帳戶資料，即表示連接成功。

[查看 MCP 工具](../mcp/tools.mdx) · [使用 AI 交易](../mcp/trading.mdx)

<details id="mcp-setup-troubleshooting">
<summary>設定疑難排解</summary>

- 若設定失敗，請檢查 `uvx --version`、wheel 雜湊值、依賴套件索引及帳戶檔案。
- 若用戶端無法啟動 MCP，請檢查產生的路徑並重新啟動用戶端。移動 wheel 或帳戶檔案後，請重新產生設定項目。
- 候選版支援請使用隨 wheel 提供的聯絡管道。請將憑證和原始記錄保留在本機。

</details>
