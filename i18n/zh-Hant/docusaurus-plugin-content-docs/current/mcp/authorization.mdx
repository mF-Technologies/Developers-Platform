在交易終端的 **API Key Management** 建立具備 **Read** 權限的 API key。將獲發設定存入用戶端使用的本機帳戶檔案。[設定用戶端](../getting-started/connect-your-ai.mdx)

## 交易權限

只為預期使用的帳戶啟用交易。交易須具備 Read 及 Trade 權限、明確啟用本機交易，以及使用支援真人表單的用戶端。本機帳戶指紋將預覽綁定至該憑證設定。請獨立核對帳戶類型。[用戶端狀態](#mcp-host-status) · [使用 AI 交易](./trading.mdx)

## 移除存取

移除或停用 MCP 設定可中斷用戶端連線。可在 API Key Management 撤銷 API key，以終止帳戶層級存取。保留未有結果的執行紀錄。
