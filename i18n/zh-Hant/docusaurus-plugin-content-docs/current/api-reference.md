當你知道需要哪項服務或 endpoint 時，請使用 API 參考。互動式參考文件由公開 OpenAPI 規格產生。

## 選擇 API

- [FxServer Trader API](./fx-server/openapi-trader.mdx) 用於交易、掛單、持倉、帳戶狀態及帳戶更新。
- [WebProxy API](./web-proxy/openapi.mdx) 用於工作階段、API keys、access tokens、帳戶資料及合約設定。
- [Realtime Chart Server API](./realtime-chart-server/openapi.mdx) 用於圖表 K 線、開市價及市場統計。

如要按任務尋找流程，請先查看 [指南](./guides.md) 或 [Trader API Client Starter Kit](https://github.com/mF-Technologies/trader-api-client-starter-kit)。
