在 Windows 将 Trader 账户连接至 AI 客户端，即可查看余额、持仓和挂单。本地 MCP 默认为只读。

[选择 AI 客户端](#configure-mcp-client)

## 1. 获取账户设置

在交易终端打开 **API Key Management**，创建具有 **Read** 权限的密钥。请使用同一账户的密钥和连接设置，并只填入设置程序指定的本地文件。

## 2. 安装并连接

**安装 uv。** 在 PowerShell 执行以下命令。

```powershell
winget install --id=astral-sh.uv -e
```

打开新的 PowerShell 窗口，执行 `uvx --version` 确认安装成功。[其他 uv 安装方式](https://docs.astral.sh/uv/getting-started/installation/#installation-methods)

**核对 wheel。** 向发布负责人索取候选版 `.whl` 文件、SHA-256 和依赖包索引网址。将 wheel 保存在固定文件夹，在 PowerShell 转到该文件夹并执行以下命令。

```powershell
Get-FileHash .\mft_trader_api_mcp-0.1.0-py3-none-any.whl -Algorithm SHA256
```

确认哈希值与收到的 SHA-256 匹配后再继续。

**运行设置。** 在同一文件夹，将命令内的索引占位值替换为收到的网址，然后运行：

```powershell
$env:MFT_TRADER_API_PACKAGE_INDEX = "<dependency index URL>"
uvx --no-config --no-env-file --managed-python --python 3.12 `
  --index $env:MFT_TRADER_API_PACKAGE_INDEX `
  --default-index https://pypi.org/simple `
  --from .\mft_trader_api_mcp-0.1.0-py3-none-any.whl trader-api-mcp-setup
```

按照设置程序显示的路径打开账户文件，填入步骤 1 的资料并保存。回到 PowerShell 按 Enter，选择 AI 客户端。程序会检查账户访问权限并输出对应的客户端配置。

<details>
<summary>账户文件字段</summary>

| 字段 | API Key Management 来源 |
| --- | --- |
| `TRADER_API_KEY` | 具有 Read 权限的 API key |
| `TRADER_API_USERNAME` | `username` |
| `TRADER_API_TRADE_KEY` | `trade_key` |
| `TRADER_API_WEB_PROXY_URL` | WebProxy REST (`webproxy_endpoint`) |
| `TRADER_API_FXSERVER_REST_URL` | FxServer REST |
| `TRADER_API_FXSERVER_WS_URL` | FxServer WebSocket (`endpoint`) |
| `TRADER_API_PRICE_AGENT_WS_URL` | Price Agent WebSocket (`price_agent_endpoint`) |
| `TRADER_API_CHART_SERVER_URL` | ChartServer REST |

请复制收到的完整网址，包括原有路径。Python 示例可能没有列出 REST 网址，请查看终端的连接设置。如有必填值缺失，请联系账户支持。

</details>

<CodeBlock className="mcpPrompt" language="text">{"显示我的账户余额、持仓及挂单，不要下单。"}</CodeBlock>

在新对话中提出以上问题。客户端调用 mFT Trader API MCP 工具并返回账户数据，即表示连接成功。

<details id="mcp-setup-troubleshooting">
<summary>设置故障排查</summary>

- 若设置失败，请检查 `uvx --version`、wheel 哈希值、依赖包索引及账户文件。
- 若客户端无法启动 MCP，请检查生成的路径并重启客户端。移动 wheel 或账户文件后，请重新生成配置条目。
- 候选版支持请使用随 wheel 提供的联系渠道。请将凭据和原始日志保留在本地。

</details>
