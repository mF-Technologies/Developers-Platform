当你知道需要哪项服务或 endpoint 时，请使用 API 参考。交互式参考文档由公开 OpenAPI 规范生成。

## 选择 API

- [FxServer Trader API](./fx-server/openapi-trader.mdx) 用于交易、挂单、持仓、账户状态及账户更新。
- [WebProxy API](./web-proxy/openapi.mdx) 用于会话、API keys、access tokens、账户数据及合约设置。
- [Realtime Chart Server API](./realtime-chart-server/openapi.mdx) 用于图表 K 线、开盘价及市场统计。

如要按任务寻找流程，请先查看 [指南](./guides.md) 或 [Trader API Client Starter Kit](https://github.com/mF-Technologies/trader-api-client-starter-kit)。
